# RepTrack Gym Tracker

RepTrack is a personal gym tracking website that helps users organize workouts and monitor their fitness progress.

## Features
- Choose between different workout routines.
- Track exercises, sets, and repetitions.
- View workout progress through an interactive dashboard.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages

## Live Website
https://sadek-almahakeri.github.io/reptrack-gym-tracker/

## Project Purpose
This project was created to practice web development, version control, GitHub collaboration, and cloud deployment.
